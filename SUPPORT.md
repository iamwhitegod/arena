# Arena Support

Arena OSS is community-supported software provided without warranty under the MIT License.

## Where to ask

- Use GitHub Issues for reproducible bugs and focused feature requests.
- Use the documentation and `arena diagnose` for installation and runtime troubleshooting.
- Use [GitHub private vulnerability reporting](https://github.com/iamwhitegod/arena/security/advisories/new) for security issues.

Before filing a bug, try the latest release and run:

```bash
arena setup --check
arena diagnose
```

Remove API keys, cookies, local usernames, media content, transcripts, and private paths before sharing output. Maintainers may close reports that cannot be reproduced, concern unsupported versions, or lack the requested information.

Arena Cloud plans and support commitments are separate from Arena OSS. No paid response time or uptime commitment applies to this repository.
