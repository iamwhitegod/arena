# Documentation archive

This directory preserves historical Arena planning and delivery records. These files explain how the project evolved, but they may describe removed flags, old defaults, incomplete experiments, outdated costs, or superseded architecture.

Use the maintained [documentation index](../README.md) for current behavior.

## Contents

- [`implementation/`](./implementation) — completion snapshots for earlier implementations.
- [`plans/`](./plans) — superseded implementation and refinement plans.
- [`reports/`](./reports) — point-in-time test and performance reports.
- [`research/`](./research) — investigations, comparisons, and external-tool research.
- [`sprints/`](./sprints) — chronological sprint and session records.
- [`validation/`](./validation) — historical validation plans and results.
- [`legacy-setup-guide.md`](./legacy-setup-guide.md) — the previous combined setup guide, retained for context.
